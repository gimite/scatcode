Scatcode Text Web Component Demo

The <scatcode-text> web component renders text with embedded domain-specific fonts using the Scatcode encoding format.

Example 1: Basic Text

This is plain text in a scatcode-text element:

Hello, World!

Example 2: Domain-Specific Font

Text with a specific domain font (e.g., sitelen-pona.scatcode.gimite.net):

󠀁󠁳󠁩󠁴󠁥󠁬󠁥󠁮󠀭󠁰󠁯󠁮󠁡󠀮󠁳󠁣󠁡󠁴󠁣󠁯󠁤󠁥󠀮󠁧󠁩󠁭󠁩󠁴󠁥󠀮󠁮󠁥󠁴󠀿toki pona

Example 3: Mixed Domains

Text with multiple domain switches:

Regular text 󠀁󠁳󠁩󠁴󠁥󠁬󠁥󠁮󠀭󠁰󠁯󠁮󠁡󠀮󠁳󠁣󠁡󠁴󠁣󠁯󠁤󠁥󠀮󠁧󠁩󠁭󠁩󠁴󠁥󠀮󠁮󠁥󠁴󠀿special font󠀁󠀿 and back to regular

Usage in HTML

<scatcode-text>Your text here</scatcode-text>

Usage in JavaScript

// Create element
const element = document.createElement('scatcode-text');
element.textContent = 'Your text here';
document.body.appendChild(element);

// Or update existing element
const el = document.querySelector('scatcode-text');
el.setText('New text');
